\section{Reproducing everything in this report}
\label{app:reproducing}

\begin{lstlisting}
git clone https://github.com/sambhavi4/bhoonidhi-records && cd bhoonidhi-records

make install     # Python venv
make data        # build the 59 catalogue records
make footprints  # harvest real acquisition footprints
make raster      # fetch the DEM the raster processes read
make up          # start the service on :5003
make test        # 126 compliance tests
make demo        # the live walkthrough
\end{lstlisting}

Prerequisites: \code{python3} $\ge$ 3.10, \code{curl} and GDAL. No database
server, no Java, no Docker.

Each writes raw responses under \code{docs/evidence/} so a reviewer can diff a
re-run against what is committed. \code{make gap} deliberately needs no
network: it audits a saved copy of NRSC's specification, which mattered because
both NRSC hosts stopped answering from the build host partway through
development.

\paragraph{A public URL.} \code{./scripts/expose\_public.sh} opens a Cloudflare
quick tunnel and prints working public URLs, including the
\code{minimal-scene-set} call and the async job exchange. The hostname is fresh
on every run and lives only while the script runs. To run the suite against it:
\code{RECORDS\_BASE=https://<name>.trycloudflare.com ./scripts/run\_tests.sh}.

\paragraph{Serving real Bhoonidhi footprints.} Put credentials in \code{.env},
then \code{./scripts/fetch\_footprints.py --source bhoonidhi}. Nothing else
changes; \code{is\_substitute\_for\_bhoonidhi} becomes \code{false} in every
response, which is the single visible difference and the reason the flag
exists.
